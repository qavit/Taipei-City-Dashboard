## 1. 建立資料表

假設使用 PostgreSQL，建議欄位型態如下：

```sql
CREATE TABLE long_term_care_people_served_tpe (
    year INTEGER,        -- 年度
    service_type TEXT,   -- 服務類別
    sub_type TEXT,       -- 服務子類別
    cms_level TEXT,      -- CMS 等級
    gender TEXT,         -- 性別
    count INTEGER        -- 人數
);

CREATE TABLE long_term_care_people_served_ntpc (
    year INTEGER,        -- 年度
    service_type TEXT,   -- 服務類別
    sub_type TEXT,       -- 服務子類別
    cms_level TEXT,      -- CMS 等級
    gender TEXT,         -- 性別
    count INTEGER        -- 人數
);
```

## 2. 匯入 CSV 檔案

請先將 CSV 檔案路徑替換為實際存放位置。

```sql
\COPY long_term_care_2_0_counts (
    county, year, service_type, sub_type, cms_level, gender, count
)
FROM '/path/to/長照2.0服務人次_雙北_處理後.csv'
WITH (
    FORMAT csv,
    HEADER true,
    ENCODING 'UTF8',
    NULL ''
);
```

## 3. 常用 SQL 查詢範例

### 3.1 統計各縣市每年服務人次總數

```sql
-- 只查詢台北市
SELECT year, SUM(count) AS total_count
FROM long_term_care_people_served_tpe
GROUP BY year
ORDER BY year;

-- 合併查詢台北市與新北市
SELECT year, SUM(count) AS total_count
FROM (
    SELECT year, count FROM long_term_care_people_served_tpe
    UNION ALL
    SELECT year, count FROM long_term_care_people_served_ntpc
) AS combined
GROUP BY year
ORDER BY year;
```

### 3.2 各服務類別人次統計（依縣市、年度分組）

```sql
-- 只查詢台北市
SELECT year, service_type, SUM(count) AS total_count
FROM long_term_care_people_served_tpe
GROUP BY year, service_type
ORDER BY year, service_type;

-- 合併查詢台北市與新北市
SELECT year, service_type, SUM(count) AS total_count
FROM (
    SELECT year, service_type, count FROM long_term_care_people_served_tpe
    UNION ALL
    SELECT year, service_type, count FROM long_term_care_people_served_ntpc
) AS combined
GROUP BY year, service_type
ORDER BY year, service_type;

-- 只查詢台北市（欄位順序並重新命名為 series, x, y）
SELECT
    service_type AS y_axis,
    year AS x_axis,
    SUM(count) AS data
FROM long_term_care_people_served_tpe
GROUP BY service_type, year
ORDER BY service_type, year;

-- 合併查詢台北市與新北市（欄位順序並重新命名為 series, x, y）
SELECT
    service_type AS y_axis,
    year AS x_axis,
    SUM(count) AS data
FROM (
    SELECT service_type, year, count FROM long_term_care_people_served_tpe
    UNION ALL
    SELECT service_type, year, count FROM long_term_care_people_served_ntpc
) AS combined
GROUP BY service_type, year
ORDER BY service_type, year;
```

### 3.5 某年度、某服務類別的性別分布

```sql
-- 只查詢台北市
SELECT gender, SUM(count) AS total_count
FROM long_term_care_people_served_tpe
WHERE year = 2023 AND service_type = '交通接送服務'
GROUP BY gender;

-- 合併查詢台北市與新北市
SELECT gender, SUM(count) AS total_count
FROM (
    SELECT gender, count FROM long_term_care_people_served_tpe WHERE year = 2023 AND service_type = '交通接送服務'
    UNION ALL
    SELECT gender, count FROM long_term_care_people_served_ntpc WHERE year = 2023 AND service_type = '交通接送服務'
) AS combined
GROUP BY gender;
```

## 4. 注意事項

1. 匯入前請確認 CSV 檔案編碼為 UTF-8。
2. 欄位名稱請依實際資料表調整。
3. 若有民國年資料，請先轉換為西元年。
4. 本 SQL 適用於 PostgreSQL，其他資料庫請依語法調整。
